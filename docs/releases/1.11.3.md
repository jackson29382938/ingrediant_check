# Ingredient Check 1.11.3 — Amazon Orders layout and coverage fixes

Multi-item order carousels and compact image-only product tiles now receive individual badges.
Only verified order cards are read; recommendations, hidden items, mismatched identities and
mixed explicit item rows remain excluded. Image alt text supplies names where titles are absent.

The page summary stays beside the order list below Amazon navigation, shows progress, and reports
rated/unrated coverage plus non-food and cancelled/returned exclusions. Camping tables and wearable
joint braces no longer count as food with missing labels. Revisiting a previously imported entry
now recognized as non-food excludes it from trends while retaining its earlier snapshot for audit.

Badges open the public product page without order context. Refresh ratings can reuse newly saved
labels/scores; missing labels remain unscored and Amazon challenges stop further public lookups.
This release cannot guarantee labels for every product. The captured PDF provided visual layout
evidence, not page HTML; matching layouts are covered by sanitized fixtures, not a signed-in live
Amazon order-session check.

Validation: 1,053 Node tests, zero-warning lint, preflight, packaging, and unpacked Chrome checks for
carousel/image-only items, summary placement, badge links, refreshed scores, legacy non-food
exclusion, monthly trends, sync, offline retention and deletion.
