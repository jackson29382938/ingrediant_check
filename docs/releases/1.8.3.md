# Ingredient Check 1.8.3 — live retailer checks and Walmart panel recovery

Walmart now restores its score panel when product-page hydration removes it without changing the ingredient label. The Chrome harness removes the panel and checks that the real extension recreates a scored panel.

Includes the latest main-branch fixes for reading Instacart's identity-bound public ingredient declarations, recognizing visible product content beneath a signup modal, and keeping Safeway/Albertsons skip links out of search ratings. Instacart's `k=` search query now reaches the food-category gate. The live-check script uses the configured HTTPS proxy, recognizes modern Costco product links, waits for missing-label fallback, reports numeric scores separately from status badges, and saves progress after each page. Known food-product fallbacks let it check all nine Kroger banners even when search results are unavailable. No new host permissions are added.

Validation: 974 Node tests, zero-warning lint and the complete unpacked-extension Chrome harness. Live checks used the cloud proxy with normal TLS certificate verification. Target and Walmart search pages were accessible; Walmart's oats product scored. The remaining six grocery-banner live checks are recorded in the [grocery audit](../GROCERY-LIVE-AUDIT-2026-10-06.md). Store challenges and missing published ingredient labels can still prevent numeric ratings. See the [proxy retailer audit](../PROXY-RETAILER-AUDIT-2026-10-06.md) for the other sampled pages and limitations.

Update files in the existing unpacked-extension folder, Reload at `chrome://extensions`, then refresh store tabs. Keeping the folder preserves the Google redirect address. Cloud Chrome certificate setup is separate from the extension and is saved in the environment configuration draft.

The development live-check script uses standard HTTP/1.1 when the cloud proxy is configured, preserving TLS verification. A bounded recheck scored Fry's and Smith's products, but remaining proxy-failed searches and Ralphs/Fred Meyer products are still unverified. This compatibility setting applies to development checks; it does not change extension users' browser networking.
