# 1.26.0

- **Sort by price per unit on any search, food or not.** Searching for something that is not food, such as a 9V
  battery, used to remove the Ingredient Check sort button from Walmart, Target and the other stores, because there
  are no ingredients to score. It now stays and offers the one entry that still makes sense, **Price per count: Low to
  High** (the "each" on a card's "$3.86/ea"). It opens the same side-panel list in its price-only form: the listings
  ranked by price per unit, with no scores, no score sliders, no saved-score lookups and no product-page requests. It
  works on all fifteen supported stores (Walmart, Target, Costco, Instacart, Kroger and its banners, Fry's, Ralphs,
  King Soopers, Smith's, Fred Meyer, QFC, Harris Teeter, Dillons, Safeway, Albertsons); Amazon already did this.
- A card that prints no unit price is priced from the pack count in its title ("2 Pack", "12 Count") when *Price per
  unit* is set to work it out, and goes to the end of the list otherwise. With unit prices switched off in the popup
  there is nothing to offer, so the button is hidden.
- Food searches are unchanged: both entries, scores and badges. Going from a food search to a non-food one (or back)
  swaps the mode, and an open list follows the new search.
- Scores, scoring rules and `RULES_REVISION` are unchanged.

Known limits: Walmart's and Target's live pages could not be captured (Walmart's bot check, Target HTTP 429), so the
browser checks use replica pages built from earlier recordings, with the unit-price text as those stores print it
("$3.86/ea", "($2.17/count)"). The thirteen other stores share the same path but have no battery search of their own in
the checks. The entry is named *Price per count* (the unit's existing name); the store's own word for it ("each",
"ea") is not repeated.

Validation: unit tests (`tests/retailer-search.test.js`), preflight, ESLint, the Chromium harness and `npm run
retailers:check`, which gains a "9v battery" search on both replicas: no badges, one menu entry, the list ranked by price
per each (Walmart) and per count (Target) with no scores, and no product page requested.
