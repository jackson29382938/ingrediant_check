# Ingredient Check 1.7.0 — settings you choose, saved everywhere, and keyboard shortcuts

You now decide how many settings to see, every setting is saved to your Chrome profile and optionally your Google account, and the health sort has a keyboard shortcut.

- **How many settings to show.** The first question in setup and the first block in Settings: Minimal, Simple, Standard, Advanced or Everything. Hidden settings keep their values and keep working. Installs from before this release keep seeing everything.
- **Sorted list.** *How much to load* (this page, about 100, 200, 300 or 500 products), a time limit for building the list (default 60 seconds), and a request pace for product pages (Gentle, Normal, Quick, Fast; Normal is how it always ran). Saved scores now fill the list as extra results pages load. The Prioritize sliders are remembered separately for the score and price-per-ounce options.
- **Keyboard shortcuts.** `Alt+Shift+H` sorts an Amazon search by Ingredient Check score in the side panel; a second command for price per ounce has no default key. Change either at `chrome://extensions/shortcuts`; Settings shows the current keys. Setup also works from the keyboard: `Enter` next, `B` back, `Shift+S` skip, `1`–`5` pick a level, `Tab` and `Space` choose, with the shortcuts listed on the page.
- **Every setting is saved.** The Chrome profile backup, the Google copy and the settings file now carry all settings, including the level, pace, sort depth, time limit and remembered priorities. A file or backup without a group of settings leaves those alone instead of resetting them. **Check my backups** compares this computer with each copy and names any setting that differs.
- **Google account.** After signing in, your picture, name and email show at the top of Settings and the sign-in prompt gives way to Save, Restore and Sign out. The profile stays on this computer. A database that is not set up for Google accounts is reported on its own instead of looking like a failed sign-in. **Keep my Google copy up to date automatically** saves every change a few seconds later, once this computer has saved to or restored from the account, so a new computer cannot overwrite your saved copy.
- Also: open the score panel expanded on product pages, and a delay before Score on hover.

## Validation and coverage

All 880 Node tests and the Chromium harness pass, including the real extension loading with the new worker script and commands. A new end-to-end test runs the real service worker and the real Apps Script against in-memory Chrome storage (with Chrome's sync item limit) and a simulated Gmail account, changes every setting one at a time, and reads each back from the Chrome profile backup and the Google copy. Deliberately breaking the backup code makes it fail by setting name. Setup was driven with real key presses in a browser.

Live Google saving needs the Apps Script deployed as a new version with the OAuth client ID configured (see [GOOGLE-SIGN-IN-SETUP.md](../GOOGLE-SIGN-IN-SETUP.md)); opening its `/exec` URL shows `"accounts":true` when it is. Signing in now asks Google for the basic `openid email profile` scopes, so you will be asked to sign in again.

## Updating

Download and extract the ZIP. For an unpacked installation, replace files in the **existing extension folder**, then click **Reload** at `chrome://extensions` and refresh shopping tabs. Keeping the folder avoids creating a new extension ID and another Google OAuth redirect. No new site access is requested.
