# Ingredient Check 1.8.0 — appearance and review completion

Settings → Appearance now ships colour scheme, score palette and accent choices throughout the extension. The toolbar badge previously ignored the selected score palette; it now uses all five bands, readable foreground text and the colour-blind palette’s distinct fills. Existing tab badges update when the palette changes, and Chrome’s retained numeric badges are recovered when the service worker restarts. Recolouring does not request a new product scan or save browsing records.

This release includes the previously unreleased setup, backup and review fixes: setup cannot overwrite an existing Google copy before restore/save confirmation, settings-file imports cannot enable automatic Google saving or Chrome backup, failed silent sign-in retains its retry, accent-only changes avoid rescanning store tabs, dark focus/contrast is corrected, the Saved toast remains available to screen readers, and malformed Settings links and section scroll offsets are handled. The popup follows the chosen settings level while retaining hidden preferences.

## Review gaps completed

- Real Chrome popup tests boot all five levels and drive storage-event changes during a pending checkbox save. Hidden values and the legacy full view are preserved.
- Real content-script tests inspect the closed shadow panel: forced dark overrides a light OS, forced light overrides a dark OS, and System follows either. Score colours match the selected palette; retailer page styles remain unchanged.
- Colour-vision regressions check all five band pairs under full-severity Machado protanopia, deuteranopia and tritanopia simulations, with an application Oklab separation floor. This is a regression check rather than a universal visual guarantee. Numeric scores and verdict words remain available independently of colour.
- Worker tests cover stored palette selection, live recolouring, suspension recovery, stale badge reads and stale startup-settings reads. Toolbar foreground/background contrast remains at least 4.5:1.

## Validation

All 929 Node tests, lint, preflight, packaging and the Chromium harness pass. GitHub CI checks Node 20/22 and the browser harness on the release commit. Existing scoring, retailer/search, setup/import privacy and profile-backup regressions remain included.

## Updating

Replace files in the existing unpacked extension folder, click Reload at `chrome://extensions`, and refresh shopping tabs. Keeping the folder preserves the extension ID and Google redirect address. No new permissions or sites are added. Live Google sign-in still requires the registered runtime redirect and deployed account backend described in [GOOGLE-SIGN-IN-SETUP.md](../GOOGLE-SIGN-IN-SETUP.md).
