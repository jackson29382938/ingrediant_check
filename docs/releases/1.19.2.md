# Ingredient Check 1.19.2

This maintenance release hardens unit-price parsing and corrects ambiguous fluid package sizing.

- Long numeric runs in listing text are bounded during unit-price parsing, preventing hostile
  product text from stalling the shopping tab.
- Conflicting fluid pack and item counts no longer produce a guessed per-fluid-ounce price.
- Ordinary consistent package counts and displayed unit prices continue to work as before.

The scoring rules and score revision are unchanged. Score accuracy remains an evidence gap: automated
tests establish consistency with the documented rubric, not independent nutrition or clinical validity.
The deployment status of the optional shared product cache cannot be verified from this repository;
its Apps Script template remains closed unless the owner explicitly sets `PRODUCTS_OPEN=true`.
