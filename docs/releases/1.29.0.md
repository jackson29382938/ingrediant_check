# 1.29.0

Implements the [November 25 codebase audit](../AUDIT-2026-11-25.md) across label reading,
shopping and comparison, retailer traffic, backups, and the Apps Script receiver.

- **Check a label with on-device AI.** On supported Chrome installations, the Library can
  estimate unfamiliar ingredients after you click the new button. A saved label retains its
  validated estimates for future comparisons.
- **Export a shortlist as CSV.** Export the selected list with current assessed scores, warning
  matches, and source information. The full label archive is still available as JSON.
- **Preserve label evidence.** The scorer and retailer reader distinguish ingredients, allergen
  declarations, and cross-contact statements. Cached photo readings retain line breaks.
  The scoring update also improves nutrition plausibility and trace-quantity parsing.
- **Coordinate retailer requests.** Badges and sorting share a paced request queue. Canceled
  source runs keep the partial list and end its loading state.
- **Refresh comparisons.** The popup can suggest higher-scoring products from a compatible
  storefront search. The Library follows current source settings and the latest search prices.
- **Reduce duplicate backups and sheet writes.** Identical complete Chrome backups can be
  reused. The Apps Script template updates affected rows in batches and exposes its revision
  for deployment checks.

See the [validation record](../CURRENT-VALIDATION.md) for coverage and deployment limits.

Scoring rules revision `2026-11-25.1`.
