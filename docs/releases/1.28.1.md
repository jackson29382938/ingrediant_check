# 1.28.1

This release ships the [November 21 codebase audit](../AUDIT-2026-11-21-FULL.md). It removes the
unused device-AI provider setting and message entry found during release review. The existing
opt-in OpenRouter features still check permission, feature consent, and key before every request.

- Walmart respects automatic rating, badges, and the Speed request budget.
- Photo checks retain editable text and highlight uncertain words. The Library accepts dropped
  or pasted photos, and source labels distinguish local OCR from AI transcription.
- Shopping lists support local export and enforce the cap across tabs. Product panels surface
  reported nutrition values, and the popup can open the Side Panel.
- Comparison uses compatible scores and units. Stop keeps partial results, and the tooltip
  follows its score chip after scrolling.
- Purchase History supports keyboard scrolling and shows ingredient differences for possible
  reformulations. Comparable snapshots can show a recorded score delta.
- USDA evidence includes the source record date and honors opt-in for manual lookup. The
  checked-in Apps Script reserves upstream request budget under a lock.

See the [full change list](1.28.0.md) and [validation record](../CURRENT-VALIDATION.md).
