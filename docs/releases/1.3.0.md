**Goals can be weighted against each other.**

When you pick two or more goals, settings shows *How much each goal counts*: a slider for each selected goal, from ×0.25 to ×4. Every goal starts at ×1.

- **How the weights combine.** Where two goals set the same dial, the dial becomes a weighted average of them, so the goal that counts more wins where they disagree.
- **Example.** Weight loss at ×3 with General wellbeing at ×1 moves natural flavours three parts of the way towards Weight loss.
- **Nothing changes at ×1 each.** That is the plain average from 1.2.0, so existing settings score exactly as before.
- **Some dials ignore the weights.** A dial only one goal sets keeps that goal's value. Vitamins & minerals still decides fortification alone.
- **The popup and first-run setup** combine goals with the same weights.

**Saved and backed up.** The weights are part of your settings: export, import, the problem report and the Chrome sync backup all include them. The Chrome backup also saves your selected goals now. Before this release it left them out.

Install: download `ingredient-check-1.3.0.zip` below, unzip it, and load the folder at `chrome://extensions` with Developer mode on (Load unpacked). Changes in 1.2.0 are in its release notes; the full history is in `docs/history/CHANGES-2026-09-26.md`.
