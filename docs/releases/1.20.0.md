# Ingredient Check 1.20.0

Adds optional **AI help** through [OpenRouter](https://openrouter.ai), using a free model and your own key.
It is off until you paste a key, turn a switch on (Settings → *AI help*) and allow Chrome's optional
permission for `openrouter.ai`. With it off, every score is exactly what 1.19.1 gave.

- **Rate unfamiliar ingredients.** An ingredient no rule recognises used to be free: it lowered coverage, and
  a list of them was declined as unreadable. With the switch on, those names (and only those names, never the
  product, store or you) are rated once by a model into one of twelve classes. The extension fixes what each
  class is worth: a plain food, culinary ingredient or vitamin counts as read and costs nothing; flavourings,
  sweeteners, added sugars, emulsifiers and gums, preservatives, colours, processing aids, isolates and other
  processed ingredients add a small charge labelled **AI estimate**, scaled by your own weight for that category.
  An estimate can only lower a score, never raise it or set a hard cap; it is limited to six ingredients and
  24 raw points per product; a rule that recognises an ingredient always wins; allergen, diet and avoid-list
  warnings never read it. Answers are kept on this computer, so each name is asked about once.
- **Read hard labels.** When on-device OCR finds no ingredient list in the product photos, a vision model can
  read it. The reply is used only if it contains an ingredient list, is kept on this computer and is never shared.
- Applies to product pages you open. Saved ratings travel with the local reading, so search results and carts use
  them afterwards. Retailer previews make no AI requests.
- The key is stored under its own storage key and is not part of any backup, settings file, sync or report.

The scoring revision advances (2026-11-01.1) to retire older calculated answers. The product entries in the
scoring corpus keep their default scores: a corpus product has no ratings. See [privacy](../PRIVACY.md#ai-help-optional).
