# Ingredient Check 1.4.3

This release makes goals, ingredient warnings and scoring controls easier to understand and keeps their setup state consistent.

- Setup shows a live summary of selected goals, or explains that Balanced/custom weights will be kept. Finishing setup explicitly saves sanitized goal importance with the corresponding weights.
- Goal help explains overlapping priorities, focused categories and custom weights without promising health or weight-loss outcomes.
- Every scoring slider shows its actual Balanced default, including 0 and 0.5. Updated help explains deductions, preference credits and score limits.
- Ingredient suggestions are shared between setup and settings, starting with palm oil and natural flavors. Suggestions do not automatically select any avoidance preference.
- Typed comma-separated entries immediately select their matching chips. Clicking a selected chip removes just that phrase. Counters report independent entries rather than lines.
- Ingredient warnings are explicitly separate from score changes; labels and packages still need checking.
- Both the product panel and hover explanation use the clearer heading **Score limits** instead of **Disqualifying**.

Validation: 641 automated tests, Chrome 153 browser/accessibility checks, ESLint, preflight and ZIP packaging passed locally. Browser checks cover the goal summary, typed ingredient/chip synchronization and a real category's 0.5 baseline. Google Cloud and backend configuration prerequisites remain unchanged.

Install: download `ingredient-check-1.4.3.zip`, extract it, and select the extracted directory using **Load unpacked** at `chrome://extensions` with Developer mode enabled. Existing scoring preferences and opt-outs are preserved.
