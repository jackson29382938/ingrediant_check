# Ingredient Check 1.15.2 — faster recall, complete Compare and release safeguards

Compare now includes every active registered store, with store names and safe public product links.
An explicit cache contract keeps compatible computed scores across routine extension updates;
identity, source, age, schema, rule and preference checks remain required. Existing product labels
remain available for local recalculation.

Seven traceable public Open Food Facts label responses in English, French and Spanish add reviewed
allergen regressions. A captured French "Sans gluten" declaration exposed a false wheat flag: absence
notes no longer feed the allergen advisory detector. Actual wheat ingredients and cross-contact
warnings still flag. This correction advances the scoring revision, so older computed scores are
recalculated from saved labels when available. Public database captures are separate from live
retailer/OCR and clinical evidence; no new health-accuracy percentage is claimed.

New diagnostic outcome/feedback uploads require the backend to advertise diagnosticsSchema 2
and confirm it in receipts. Older backends keep the bounded retry queue local and Settings explains
the required update. Deploy the new docs/apps-script.gs as a new Apps Script deployment version;
private history and settings protocols remain separate.

Installation now starts with the prebuilt Chrome/Firefox ZIPs. Source packaging documents Node
and Python requirements. Purchase statistics explain entries versus quantities and what intervals
mean. Privacy copy matches the actual Google scopes. Website checks cover public pages, clean URLs,
mobile/desktop layouts and security headers; WEBSITE_URL can enable checks of the live deployment.

Publishing now requires the full reusable CI suite: both Node versions, preflight, lint, Chrome,
Firefox, zero-warning Mozilla validation and website checks. Both browser ZIPs are published together.
The Firefox ZIP still requires Mozilla signing for permanent installation. Google OAuth redirect
registration, Apps Script deployment, Vercel project access and the production website URL require
access to those external accounts; this release does not claim to complete those account changes.
