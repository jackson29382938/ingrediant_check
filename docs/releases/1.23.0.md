# 1.23.0

- Simplify the popup: keep the active goal visible, reveal goal choices on
  demand, and give “Check a label” a clear primary action.
- Add consistent navigation across settings, labels, purchase history, and
  reporting, with an active-page indicator and a keyboard skip link.
- Add labeled settings search, a no-match recovery message, and an explicit
  “Show essentials” shortcut. Existing preferences and saved data are preserved;
  choosing Essentials changes only the existing detail-level preference.
- Put detailed view choices behind a native disclosure, improve narrow-screen
  spacing and control sizes, and honor reduced-motion preferences.
- Fix checked-label panels retaining their light scheme when the library
  switches to dark mode. Keep score calculations unchanged.

Validation: 1,330 Node tests, ESLint, preflight, isolated Chromium screen and
history checks, content-script browser regression checks, Chrome/Firefox
packaging, and Firefox package lint. Screenshots cover desktop, narrow, and dark
layouts. The managed browser blocks unpacked-extension installation; these
checks use actual pages with synthetic storage and do not access user accounts.
