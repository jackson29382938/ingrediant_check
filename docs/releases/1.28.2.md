# 1.28.2

This release ships the [November 21 codebase audit](../AUDIT-2026-11-21-FULL.md).
The Chromium retailer test now waits for the sorted list to render after Stop. This fixes
the validation race that blocked package publication for the 1.28.1 tag.

- Walmart respects automatic rating, badges, and the Speed request budget.
- Photo checks highlight uncertain text and distinguish local OCR from AI transcription.
- Shopping lists support local export and enforce limits across tabs.
- The sorted list keeps partial results when stopped and compares compatible scores and units.
- Purchase History supports keyboard scrolling and shows ingredient differences for possible reformulations.
- USDA evidence includes the source record date. The Apps Script template reserves quota under a lock.

See the [1.28.1 audit release notes](1.28.1.md) for the full set of changes and the
[validation record](../CURRENT-VALIDATION.md) for coverage.
