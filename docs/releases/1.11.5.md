# Ingredient Check 1.11.5 — adjustable instant score recall

Search and cart pages show fresh saved ratings without new product lookups. Older ratings within
an adjustable grace period stay visible as “saved” while a paced background refresh reads missing
or stale labels. Failed refreshes retain their original timestamps. Product/settings/version checks
still apply, and purchase-history snapshots remain unchanged.

Settings → Advanced → Speed and freshness adds independent saved-score, in-memory reading, and
background-refresh switches plus a 0/7/30-day grace selector. Defaults: all switches enabled,
seven-day grace, existing Balanced 30-day freshness and Normal pace. Recent local readings use a
bounded 256-entry/2 MB memory cache that invalidates on writes or deletion. Repeated products share
requests. The controls survive settings backup/restore; no additional account data is collected.

Validation covers local-cache invalidation and memory limits, backup/restore, controls surviving
reload, held background refreshes on search/cart pages, repeated-product request counts, disabled
refresh/automatic scoring, fresh-only behavior and recall opt-out. Existing store, order, OCR,
privacy and accessibility checks remain in the full test and unpacked-Chrome suites.
