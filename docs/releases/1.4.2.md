# Ingredient Check 1.4.2

Setup now recommends and checks all four final choices: automatic search rating, owner-kept certification lookups, on-device label OCR, and Open Food Facts barcode fallback. Uncheck any choice to opt out. Existing saved opt-outs are preserved; diagnostics and anonymous product exchange are separate and remain off.

- Avoid-list examples show `palm oil, natural flavors`. Commas and new lines separate independent phrases across setup, settings, imports and backups; displayed entries use comma spacing.
- Finish requests Chrome's optional barcode permission when that choice is checked. Denial returns to setup with the choice unchecked. Barcode requests cannot run without that permission.
- Google account setup includes the supplied public OAuth client ID, a redirect-copy button, and links to Google Cloud credentials and Google app connections. No client secret is included.
- Setup completion links directly to Chrome profile settings and Google account backup settings. These remain independent backup routes.
- Google authorization/configuration errors receive a separate explanation from user cancellation. Tokens remain ephemeral; no additional Google scopes are requested.
- Runtime defaults and source-specific cache fingerprints now agree with the recommended choices.

Live Google login still requires the installed extension's redirect registered in the OAuth client's authorized redirects, test-user access if applicable, and the same public client ID configured in the Apps Script backend followed by deployment. This release does not perform that console setup or verify live sign-in.

Validation: 639 automated tests passed, Chrome 153 extension browser checks (including independent avoid entries, default choices, preserved opt-outs and redirect copying), ESLint, preflight and extension packaging.

Install: download `ingredient-check-1.4.2.zip`, extract it, and select the extracted directory using **Load unpacked** at `chrome://extensions` with Developer mode enabled. GitHub publication is separate from Chrome Web Store publication.
