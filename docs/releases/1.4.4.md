# Ingredient Check 1.4.4

This release fixes imported goal settings and strengthens the prepared Google account backup receiver.

- Fractional goal importance such as 1.33 is preserved by settings sliders instead of being rounded to a quarter step.
- Balanced is normalized as the baseline, rather than an invisible extra selected goal in imports, backups or goal labels. Actual preset scoring weights remain unchanged. The rule revision retires stale cached labels/scores.
- The Apps Script deployment template includes the same public Google OAuth client ID as the extension. A Script Property still overrides the template for another client. No client secret is used.
- Google account tokens with conflicting audience/authorized-party values, malformed subjects, or expired/non-numeric expiry metadata are rejected before accessing account rows.

Validation: 644 automated tests, Chrome 153 extension browser/accessibility checks, ESLint, preflight and ZIP packaging passed locally. The browser check explicitly verifies a saved 1.33 goal priority.

The updated backend template must be deployed by its owner to protect live account requests. Google OAuth redirect registration and signed-in save/restore testing still require the installed extension and an authenticated Google project session. Chrome Web Store publication is separate from this GitHub release.

Install: download `ingredient-check-1.4.4.zip`, extract it, and use **Load unpacked** at `chrome://extensions` with Developer mode enabled.
