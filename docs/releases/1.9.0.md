# Ingredient Check 1.9.0 — cart item ratings

Cart pages now display item ratings for all 16 listed stores: Amazon, Target, Walmart, Costco,
Instacart and the eleven grocery banners. Cart drawers on supported product/search pages use the
same reader. Saved scores show first; automatic rating reads missing public product labels, two at
a time within the Speed budget. The existing automatic-rating switch now says **Rate search
results and cart items**. Existing opt-outs are preserved.

Cart lookups omit cookies and the cart referrer. They forward public product identity only, never
cart URL parameters, quantities, totals, delivery information or account/payment fields. Cart
controls remain unchanged. Missing labels stay unavailable, non-food items are declined, and
recommendations and saved-for-later rows are excluded. Navigation into checkout stops reading and
removes ratings. No broad host permissions or Google/cart uploads are added.

Includes the preceding Walmart panel recovery, Instacart and grocery fixes, remaining grocery
live audit and standard HTTP/1.1 compatibility for cloud development checks.

Validation: 995 Node tests, zero-warning lint, preflight, store-ready packaging and the complete
unpacked-extension Chrome harness. Cart fixtures exercise all 16 stores, item changes, saved-score
reuse, missing labels, mixed carts and private-data boundaries; a Target search drawer also opens
and closes in Chrome. Full live filled-cart coverage is still pending. Retailer challenges and
unpublished ingredient labels can prevent ratings; see [store coverage](../STORES.md).

For an unpacked install, update files in the existing extension folder, Reload at
`chrome://extensions`, then refresh store tabs. Keeping the folder preserves the Google redirect
address. The release does not change your Google Cloud OAuth configuration.
