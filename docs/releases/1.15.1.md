# Ingredient Check 1.15.1 — Firefox validation and safer panels

The Firefox package now validates with zero errors and zero warnings using web-ext 10.0.0.
Chrome-only offscreen and side-panel APIs are replaced by native Firefox implementations at build
time. Concurrent Firefox OCR requests wait for the same host to finish loading, preventing an
early request from using an unready worker.

Score panels use DOMPurify and sanitized DOM fragments instead of assigning dynamic innerHTML.
The modern-HTML sanitizer fails closed if parsing fails. The OCR bundles remove obsolete
string-evaluation fallbacks and use analyzer-compatible WASM feature probes. All vendor changes
are reproducible from pinned, checksum-verified upstream inputs; licenses are included.

Validation covers both browsers, panel injection attempts and parser failure, Firefox OCR image
recognition, sidebar access, settings and history, and search/product/cart fixtures for all 16 stores.
Scoring rules are unchanged, so existing score caches remain valid.

Firefox users: upload ingredient-check-1.15.1-firefox.zip to Mozilla, replacing the 1.15.0 submission.
The GitHub ZIP is unsigned until Mozilla signs it. Reviewer notes and vendor reproduction steps
are in docs/MOZILLA-REVIEW.md. Google OAuth still needs the Firefox redirect registered in your
Google Cloud project. Chrome users should update files in the existing install folder and Reload
to preserve their extension ID, local data and Google redirect.
