# Ingredient Check 1.13.0 — visual purchase insights

History & sync now has a scan progress bar, purchase summary cards, an interactive score timeline,
a score distribution, order summaries and sortable/filterable imported items. Filter by product,
date, status, rating availability, recorded warnings and score range. Monthly/yearly views show
coverage and keep recorded scoring setups separate. Charts are local SVGs with keyboard-readable
points, data tables, responsive layout and theme/palette support; no chart service is contacted.

Recorded scores remain the default. The current-goals comparison recalculates locally using your
saved goals, weights and warning choices without rewriting purchase snapshots. New snapshots
retain bounded scoring inputs including available nutrition and certifications. Older ingredient-only
records have explicitly approximate comparisons; missing labels remain missing. Changes in Settings
update an open comparison dashboard automatically.

Order groups are hashed separately from product identities. Multiple product entries in one order
add up under that order, rather than pretending to be multiple orders or quantities. Revisit older
order pages to fill missing group identifiers. Choose equal-product or equal-order averages.
Statistical details include median, sample SD, quartiles, range and optional IQR/range bars or
approximate 95% order-cluster confidence intervals. Their sample-size and grouping requirements
are explicit; intervals do not measure medical health or label accuracy.

Packaging also creates dist/unpacked containing only extension files. The production ZIP is about
3.8 MB and the extracted extension about 7.5 MB; loading the entire development checkout counts
old ZIPs, tools and Git files. For new installations, use the extracted release folder or dist/unpacked. Existing installations should replace extension files in their current folder and Reload, keeping that path to retain their unpacked extension ID, local history and OAuth redirect.

Redeploy docs/apps-script.gs on the existing web-app URL to preserve the new grouping and scoring
input metadata across devices. Existing local snapshots and ordinary sync remain compatible with
older servers, but those servers cannot retain the added fields.

Validation covers order/item totals, weighting, missing values, grouping preservation, filtering,
comparison immutability, statistical prerequisites, year/pagination scans and the real dashboard
in unpacked Chrome, including live preference changes, chart controls and mobile dark layout.
Retailer and account requests use controlled fixtures rather than private live purchase histories.
