# Ingredient Check 1.15.0 — Chrome and Firefox

Every release now builds Chrome and Firefox ZIPs from the same source and version. Firefox uses
its native sidebar, an event background page and a hidden extension frame for local OCR; both
Promise and callback API calls work through the shared code. Message authorization checks the
actual extension origin in both browsers. Scoring, cache recall, settings and purchase analytics
remain shared. Firefox uses its own profile sync and asks for optional data-sharing consent.

CI runs real Chrome and Firefox checks, including Firefox search/product/cart fixtures for Amazon
and all 15 retailer previews, extension UI, local OCR startup and purchase statistics.

The Firefox ZIP is unsigned. Use about:debugging for temporary loading, or submit it to Mozilla
for signing before permanent installation. Requires Firefox 142+; the stable add-on ID is
ingredient-check@jackson29382938.github.io. Google sign-in needs the exact Firefox redirect shown
in setup registered in the existing OAuth Web client, alongside existing Chrome redirects.
See docs/BROWSERS.md for installation, testing and signing instructions.

Chrome users: update files in the same existing install folder and Reload to preserve the
extension ID, Google redirect and local history. Both production ZIPs remain about 3.8 MB each.
