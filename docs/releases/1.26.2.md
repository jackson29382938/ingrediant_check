# 1.26.2

Ingredients that were written in a way the reader did not understand were charged nothing, and the score said so
with a straight face: silence reads as cleanliness. This release reads twelve such ways of writing. A list written
the usual way scores exactly what it did.

- **A heading without its colon.** A page prints "Ingredients" on a line of its own and a label photo loses the
  colon, so the first ingredient, the one that weighs most, arrived as "ingredients sugar" and matched no rule.
  "INGREDIENTS SUGAR, WATER, SALT" scored 80; it now scores 63, as "Sugar, Water, Salt" does. "Ingredient list:",
  "Other ingredients:", "List of ingredients:" and the heading in each label language are read the same way.
- **Ligatures, full-width letters and decomposed accents.** OCR and text copied from a PDF write "fi" and "fl" as
  one character: "Water, artiﬁcial ﬂavor, Salt" scored 90 and now scores 41, as the plain spelling does. "azúcar"
  typed as a letter plus a combining accent, and "ｓｕｇａｒ" in full-width letters, are read as the words they are.
- **Direction marks.** Amazon prints invisible left-to-right and right-to-left marks in its product details. "Sugar"
  followed by one was charged nothing.
- **Punctuation at the ends of an entry.** Quotation marks round a word, a colon, exclamation mark or question mark
  after it, and ®, ™ and © signs: `"Sugar"`, `Sugar!`, `Sugar:` and `Sugar™` each scored 90 in a list that scores 65.
- **"Or" and a slash.** "Oats, sugar or honey, Salt" scored 90 (now 64, as the comma list does) and "Water,
  sugar/dextrose, Salt" 90 (now 61). A bilingual "Sugar/Sucre" is charged once, as the English label is. A pair a rule
  already reads whole ("canola/soybean oil") or that charges nothing ("salt/pepper") stays one entry.
- **A list set out with spaced dashes, slashes or tabs** and no comma at all, as some Italian labels print it ("farina di
  grano tenero - zucchero - olio di semi di girasole - sale") and as a list copied from a table arrives. Four items
  or more are a list. Two or three ("Oats - Sugar - Salt", 90, now 65) are a list only when every item is an
  ingredient the rules read and one of them is charged, so a product name set out with dashes ("Organic Raw Almonds
  - Unpasteurized - 16 oz") stays one entry.
- **A weight after the ingredient.** "Oats, Sugar 5g, Salt" scored 90 and now scores 65; "Sugar (5 g)" and "Sugar -
  5g" read the same way. A weight says nothing about the share of the product, so the entry keeps the weight of
  its position. A number with no unit stays part of the name ("Red 40", "Polysorbate 80"). An entry that is nothing
  but a weight ("…, 32 oz") is a pack size from a product name and still counts as unread, and a claim such as
  "11g protein" is not turned into an ingredient.
- **Two words run together.** "Water, SoybeanOil, Salt" scored 90 and now scores 63, as "Soybean Oil" does;
  "CornSyrup", "NaturalFlavors" and "HighFructoseCornSyrup" likewise. The space goes back only when the rules then
  charge more or read both words, so "NutraSweet", "SunButter" and "McCormick" are left as written.
- **German without its umlauts.** "Hafer, Sonnenblumenoel" (and SONNENBLUMENOEL on a label set in capitals) scored 90
  and now scores 63, as "Sonnenblumenöl" does; "gehaertetes Pflanzenfett", "Kaese" and "Saeuerungsmittel" are read.
  The umlaut is taken only when the rules then see more, so "blueberries", "aloe" and "Sauerteig" are untouched.
- **Scoring is about twice as fast.** Which rules read an entry is now remembered by the entry's text instead of
  being worked out four or five times a list: 0.73 ms to 0.37 ms a product across the calibration corpus, 3.3 ms
  to 1.7 ms for a fortified cereal, 8.3 ms to 2.3 ms for a sixty-entry list (the median of five runs, Node 22, on
  lists whose entries had been seen before, which on a results page is most of them).
- **Open Food Facts is not asked twice about a barcode it does not hold.** "No such product" and "no ingredient
  list" were never kept, so every visit to such a product sent the barcode again. The answer is now kept for three
  days, as a USDA miss already was. A request that failed (offline, rate-limited, a server error) is still not
  kept, and **Look up** in the label library always asks.
- The diagnostics status line in Settings gets a reply when storage fails, instead of waiting for one that never came.
- The test workflow builds both store packages on every push, so a packaging failure no longer first appears after
  a release tag has been pushed.
- **The workflows run actions by commit, not by tag.** `actions/checkout` and `actions/setup-node` were named as
  `@v6`, a tag their owner can move to other code, and the release workflow runs with permission to write to this
  repository. Each is now pinned to the commit behind v6.1.0 and v6.5.0, and `tests/workflow-pins.test.js` fails
  on a tag.
- The words of an ingredient panel that no rule charges (about a hundred lines of `score.js`) are a rule file of
  their own, `src/engine/db/vocabulary.js`, unchanged, and hashed with the other rule sources.

`RULES_REVISION` is `2026-11-14.2`, so saved scores are worked out again. No product in `tests/corpus.json` moved.
The 1.26.1 engine was run against this one over every list-like string in the test suite (2,650 of them): the only
readable lists whose score moved are written in one of the formats above, or are a heading or a product name that
happened to be among the strings ("Rice 1,000 g" now reads as rice).

Validation: `npm test` (1,405 tests), `npm run preflight`, `npm run lint`, `npm run pack`, the real-Chromium
harness (`npm run harness:ci`), the retailer and website checks, `web-ext lint` on the Firefox package and the
Firefox harness in Firefox 157. New tests: `tests/invariants.test.js` (one per format above, and that a remembered
answer is the answer a fresh engine gives), `tests/background.test.js` (remembered misses, the status reply) and
`tests/workflow-pins.test.js`.

Known limits: two words run together with no capital between them ("soybeanoil", "SOYBEANOIL") and a list with no
separator at all ("Water Sugar Salt") are still one unread entry. "ss" written for "ß" is not turned back. A weight
in litres is not dropped.
