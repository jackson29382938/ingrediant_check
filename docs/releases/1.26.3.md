# 1.26.3

- Automatic Google backup pauses if the saved copy has changed and differs from this browser's settings. Use **Check my backups** to compare the copies, then restore the Google copy or save your browser's settings explicitly.
- Signing into a different Google account clears the previous account's backup link.
- The updated Apps Script adds a server-side check for competing automatic saves. The database owner must deploy the updated script to activate that check.
