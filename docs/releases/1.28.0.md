# 1.28.0

This release implements the November 21 codebase audit across retailer controls, label reading,
comparison, purchase history, settings, and the Apps Script template.

## New features

- **Nutrition Facts side-by-side badge lens.** Product score panels and hover breakdown cards now display
  compact normalised nutrition pills (`Added sugar`, `Sugar`, `Sodium`, `Fiber`, `Protein` per 100 g / 100 ml)
  whenever nutrition facts are available, highlighting high added sugar/sodium and strong fiber/protein
  without altering ingredient-quality arithmetic.
- **Universal drag-and-drop & clipboard-paste OCR in Labels & Saved Products.** `library.html` now includes
  a drag-and-drop photo dropzone and listens for pasted label screenshots (`Ctrl/Cmd+V`) to run on-device
  OCR directly into the ingredient checker.
- **One-click Side Panel launcher & cleaner-swap callout in the popup.** The toolbar popup now includes a
  **Side panel** button to jump straight into the comparison workspace, and surfaces the top cleaner swap
  from the current sorted list when viewing a low-scoring food product (`< 60`).

## Security, reliability & backend

- **Fail-closed offscreen OCR sender check.** `src/offscreen/ocr.js` `fromWorker()` now requires an explicit
  matching `sender.id === chrome.runtime.id` (rejecting missing or mismatched sender IDs).
- **Storage & permission race fixes.** Added `area !== 'local'` guards and per-key `pendingKeys` tracking
  in `src/options/popup.js`, plus `area !== 'local'` guards and `chrome.permissions.onRemoved` listeners for
  `openrouter.ai` and `api.nal.usda.gov` in `src/options/settings-database.js`.
- **OCR timeout worker cleanup.** `src/options/library.js` now invokes `frame.contentWindow.resetWorker()`
  in `finally` so timed-out photo reads never leave a Tesseract worker running behind a removed iframe.
- **Apps Script schema-version check.** Added `BACKEND_SCHEMA_VERSION = 2` in both
  `src/engine/db/diagnostics.js` and `docs/apps-script.gs` (exposed in `doGet`), verified at build time by
  `scripts/preflight.mjs`.
- **Expanded preflight locale coverage.** `scripts/preflight.mjs` now verifies all i18n keys used in
  `src/options/library.html` and `src/options/library.js` across every shipped locale.

## Consent, evidence and shopping

- Walmart honors automatic rating, badges and the Speed request limit. Sponsored hiding and the
  sort menu remain available independently.
- Queued OpenRouter work checks current permission, feature consent and key before each request,
  including a retry. Photo evidence identifies the transcription source. Local OCR separates
  ingredient declarations from advisory and importer text and flags uncertain readings for review.
- Shortlist updates use one worker writer, including two-item saves. Existing overflow is
  recoverable, and saved lists can be exported to a local JSON file.
- Best-value badges use comparable scores and unit prices. Sorted-list hover works after scrolling.
- Purchase History tables support keyboard scrolling. Possible reformulations now include an
  ingredient comparison and show score changes only for matching recorded setups. New snapshots
  retain the original label separators for replay.
- USDA evidence distinguishes source record date from retrieval date. The checked-in Apps Script
  reserves upstream quota under a lock. Deploying the updated template is a separate operation.
- Live tooling distinguishes HTTP accessibility from extension results. Release validation now
  includes the lint fix that blocked package publication for the v1.27.0 tag.
