# Ingredient Check 1.11.2 — visible order scores and page average

Amazon Orders now explains when purchase import is off or the extension is paused, with a
History & sync settings button. After import, the page summary shows an average out of 100
for rated purchases on that page. Unavailable labels, cancellations and returns do not enter
that average. Individual scores remain beside product titles.

The order reader also recognizes separate product-box tiles within multi-product shipment
layouts, without treating sidebar Buy it again recommendations as purchases.

Includes the latest badge navigation and cart explanation changes from main. Purchase history
still requires explicit opt-in. Reload the extension and then refresh an existing Orders tab.
The page average is a summary of saved snapshots, while monthly history groups separate scoring
setups and versions. No live signed-in Amazon order page was available for verification.

Validation: 1,050 Node tests, zero-warning lint, preflight, packaging and controlled unpacked Chrome
order-page checks for disabled import, product tiles, individual ratings and average coverage.
