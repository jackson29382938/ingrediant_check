# 1.27.0

This release delivers the 2026-11-20 line-by-line code audit fixes across the scoring engine, background worker,
settings page, manifest, and Google Apps Script backend, alongside new comparison and purchase-history features.

## New features

- **Best value clean preset & Pareto badges in the sorted list.** The side panel and sorted tab now include a
  **Best value clean** starting point that weights health score and unit price together, and mark listings on the
  Pareto frontier with a **Best value** badge when no other listing in the list beats them on both score and unit price.
- **Cleaner swap suggestions.** Low-scoring listings (under 60) in the sorted list now highlight the highest-scoring
  same-category alternative in the current search when one beats it by at least 15 points.
- **Reformulation alerts in Purchase History.** Repeat purchases of the same product whose saved ingredient list
  changed between orders now appear in a dedicated **Reformulations detected** section with date range, score delta,
  and an expandable before/after ingredient comparison.

## Scoring engine

- **Compound-ingredient penalty matching.** `penaltiesFor()` now checks both the original and stripped ingredient
  forms so parenthetical-only or stripped modifiers do not hide a penalty.
- **Per-entry cap tracking.** `capsHit` now evaluates score caps per entry rather than against the full joined list.
- **Post-entity HTML tag cleanup.** `cleanText()` runs a second tag/angle-bracket cleanup pass after decoding HTML
  entities so entity-encoded tags cannot leak into ingredient tokens.
- **Small-serving nutrition scaling.** `normaliseNutrition()` scales macro plausibility tolerances for tiny servings
  instead of rejecting valid concentrates and seasonings.
- **Footnote digits 1–19.** Footnote stripping now handles double-digit footnote markers (1–19) while keeping real
  ingredient numbers (Red 3, Vitamin D3, Polysorbate 80) intact.
- **Rule-table cleanup.** Removed a duplicate `fib` token in `BIO_FUSED` and hoisted `cookingFatRule` out of the
  scoring hot loop.

## Worker, settings & security

- **MV3 cold-start and concurrency fixes.** Awaited persisted `productsBackoff` before flushing shared product queues,
  added a `chrome.alarms` (`ic-products-flush`) fallback when service-worker timers are evicted, and serialized sorted
  panel state transitions (`openSortedPanel`, `followSortedSearch`, `updateSortedResults`, `endSortedList`).
- **Hardened message senders and permissions.** `isOwnExtension()` now fails closed on `sender.id === id`, tab sender
  checks reject subframes (`frameId !== 0`), all 21 Amazon `host_permissions` require `https://`, and preview retailer
  content scripts exclude checkout/account paths via `exclude_globs`.
- **Network timeout and badge fidelity.** Raised `networkRequest` timeout to 22 seconds, preserved neutral `#565959`
  action badges for label indices, and cached `diagnosticCapability` in `chrome.storage.session`.
- **Settings reliability.** Added a `scoringDirty` guard on `pagehide`, per-key `pendingKeys` tracking in
  `storage.onChanged` (with `area !== 'local'` guards across listeners), atomic settings import, localized permission
  denial/load errors, and `textContent` clearing in preset comparison views.

## Apps Script backend

- **Batched history writes & cache safety.** `writeHistory()` appends new rows in a single `setValues()` call,
  `writeRows()` appends before trimming to avoid frozen-row deletion errors and escapes leading apostrophes, and
  `usdaLookup()` guards against 95 KB `CacheService` limits with safe JSON parsing and a 30-minute empty-miss TTL.
- **Auth header & lock tuning.** `accountId()` passes Google access tokens via the `Authorization: Bearer` header
  instead of a query parameter, and write locks use an 8-second timeout.

Rules revision `2026-11-20.1`: every cached score is worked out again.
