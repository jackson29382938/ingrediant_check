# Ingredient Check 1.11.1 — purchase history and trends

Includes the setup-guided Amazon.com order import and purchase-only dashboard from 1.11.0:
automatic/manual account sync, first rating snapshots, saved-score reuse, missing-label coverage,
return/cancellation exclusions, export and confirmed deletion. Only opened order pages are imported;
full history crawling is not implemented.

The prepared backend now locks history reads alongside writes/deletions, so another device cannot
read a partly cleared account. It writes only changed records in each batch and deletes contiguous
account rows together, keeping larger histories practical. Legacy Amazon order-pagination ref paths are also covered.

Validation: 1,041 Node tests, zero-warning lint, preflight, packaging and unpacked Chrome checks.
The order/browser checks cover first/older pages, cached/public ratings, returns, purchase-only
trends, automatic/manual sync, offline retention and deletion using controlled OAuth/backend fixtures.
