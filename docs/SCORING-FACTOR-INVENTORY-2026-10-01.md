## All category defaults

| Control | Default | Role | Review decision |
| --- | --- | --- | --- |
| processing | 1 | base | How industrially processed the product is, on the NOVA 1–4 scale. This sets the starting score before individual ingredients are considered. Usually the single strongest signal. |
| colour | 1 | cap | Synthetic dyes such as Red 40, Yellow 5, and titanium dioxide. Sets a hard ceiling on the score. |
| artificialSweetener | 0.5 | cap | Sucralose, aspartame, acesulfame potassium, saccharin. Uses a moderate ceiling at the default weight of 0.5. Stronger avoidance remains an optional preference. |
| sweetener | 1 | penalty | Erythritol, xylitol, maltitol, allulose, stevia extract, monk fruit. Lower this if you use these deliberately. Below 0 it counts in favour of the product — a goal can set that. |
| preservative | 1 | penalty | Sodium benzoate, potassium sorbate, nitrites, sulfites, EDTA and similar. |
| strongPreservative | 1 | cap | Synthetic antioxidant preservatives that set a hard ceiling rather than a point penalty. |
| flavour | 1 | penalty | Artificial flavours, bare "flavouring", and flavour enhancers such as vanillin and maltol. |
| naturalFlavour | 1 | penalty | An undisclosed proprietary blend. Separate from artificial flavours so a goal that does not care about it (weight loss) can nearly switch its points off. Below 0 it counts in favour of the product — a goal can set that. The dial moves points only: an added flavouring still makes the product ultra-processed (NOVA 4), which sets its starting score. |
| glutamate | 1 | penalty | Monosodium glutamate, yeast extract, hydrolysed protein, disodium inosinate. |
| texture | 1 | penalty | Xanthan and guar gum, mono- and diglycerides, polysorbates, methylcellulose, modified starch, maltodextrin. |
| carrageenan | 1 | cap | Treated separately from other thickeners because of its association with gut inflammation. Sets a ceiling. |
| processingAid | 1 | penalty | Phosphates, industrial acids, anti-caking agents, dough conditioners, aluminium compounds. |
| refinedOil | 0.5 | cap | Canola, soybean, sunflower, safflower, corn, cottonseed, and unspecified "vegetable oil". Default weight 0.5 uses a moderate ceiling; stricter goals can restore the stronger avoidance preference. This is not a toxicity estimate. |
| transFat | 1 | cap | Industrial trans fat. The most severe ceiling in the system. |
| saturatedFat | 0 | penalty | OFF by default. Conventional nutrition guidance penalises saturated fat; other frameworks do not. Raise this if you want butter, cream, coconut oil and fatty meat to lower a score. Requires nutrition data on the page. |
| sugar | 1 | penalty | Cane sugar, dextrose, glucose syrup, agave, fruit juice concentrate. Sugar occurring naturally in whole fruit or dairy is never counted here. |
| traditionalSweetener | 1 | penalty | Honey, maple syrup, molasses, coconut and date sugar, fruit juice concentrate. A light touch by default. Below 0 it counts in favour of the product — a goal can set that. |
| industrialSyrup | 1 | cap | HFCS and glucose-fructose syrup. Sets a ceiling rather than a point penalty. |
| naturalSugar | 0 | penalty | OFF by default. Sugar from whole fruit, dates, and dairy lactose. Raise this if you want total sugar counted regardless of source. |
| totalSugar | 0 | penalty | OFF by default. Scores grams of sugar from the nutrition panel, independent of ingredient source. Requires nutrition data on the page. |
| grain | 1 | penalty | Refined flour, isolated starches and milled grain ingredients. Explicit whole-grain flour is exempt. Gluten is a separate preference, off by default; use allergen warnings for avoidance. |
| gluten | 0 | penalty | OFF by default. Optional ingredient preference for wheat, barley, rye and related grains. Gluten alone is not a quality defect. Use allergen warnings for gluten avoidance; a score cannot establish safety. |
| isolate | 1 | penalty | Soy protein isolate, pea protein, whey and milk protein isolate, textured vegetable protein, caseinate. Below 0 it counts in favour of the product — a goal can set that. |
| plantDefense | 0 | penalty | OFF by default. Beans, lentils, peas, peanuts, soy, tree nuts and seeds. Only the animal-based goal turns this on. |
| fortification | 0 | penalty | OFF by default. Added folic acid, reduced iron, thiamin mononitrate, vitamin D and similar. Fortification alone does not establish ultra-processing; the vitamins goal makes it a plus. Below 0 it counts in favour of the product — a goal can set that. |
| dairyProcessing | 0 | penalty | OFF by default. Ultra-pasteurised and homogenised dairy as an optional processing preference. Raw milk and A2 claims earn no automatic quality bonus. |
| reducedFatDairy | 0 | penalty | OFF by default. Skim, low-fat, reduced-fat and nonfat milk, yogurt, cheese and kefir. A weight-loss preference can reward it, without estimating calories. Below 0 it counts in favour of the product — a goal can set that. |
| addedSugar | 0 | penalty | OFF by default. Uses declared added-sugar grams, normalized to 100g or 100ml when a basis is available. Replaces ingredient sugar deductions when usable quantity data exists. Missing quantity stays unknown. |
| carbohydrate | 0 | penalty | OFF by default. An optional low-carb preference based on declared carbohydrate grams. Requires nutrition data; ingredient names alone cannot establish carb content. |
| sodium | 0 | penalty | OFF by default. Scores milligrams of sodium against per-serving thresholds. Requires nutrition data on the page. |
| fibre | 0 | bonus | OFF by default. Awards points for fibre per serving. Requires nutrition data on the page. |
| protein | 0 | bonus | OFF by default. Awards points for protein per serving. Requires nutrition data on the page. |
| organic | 1 | bonus | Organic claims earn credit. Claims found only in the seller-written title or bullets count at half weight and are labelled unverified; this score does not verify certification. |
| animalWelfare | 1 | bonus | Sourcing claims about how an animal was raised or caught. |
| fermented | 1 | bonus | Cultured dairy, kefir, kimchi, sauerkraut, sourdough. Preservative systems that merely use the word "cultured" are excluded. |
| unrefined | 1 | bonus | Butter, ghee, tallow, olive, coconut and avocado oil, cold-pressed oils, and unrefined salt. |
| nonGmo | 1 | bonus | Non-GMO Project verification and equivalent claims. |
| traditionalPrep | 1 | bonus | Sourdough, sprouted, soaked, dry-aged, and long-fermented preparation. |
| simplicity | 1 | bonus | Rewards recognized single-ingredient whole foods. List length alone is not a defect. |
| provenanceVerified | 1 | bonus | Independently audited standards — American Grassfed, Animal Welfare Approved, USDA Organic, Global Animal Partnership steps, MSC. For a single-ingredient food like ground beef this is where nearly all the real variation lives. |
| provenanceClaimed | 1 | bonus | Label claims with no audit behind them — "grass-fed", "pasture-raised", "no antibiotics". Worth roughly half a verified certification. Lower this to zero if you only want to credit audited claims. |
| provenanceUnknown | 1 | penalty | Applies only to whole animal foods that make no sourcing claim at all. Missing certification is uncertainty, not proof of a production method; this optional preference reserves points for sourcing evidence. Set to 0 to score unlabelled meat purely on its ingredients. |
| hollowClaims | 1 | flag | Surfaces claims that sound like quality signals but are not — "USDA Inspected" (mandatory for all meat), "no hormones added" on pork and poultry (already illegal), "natural", "farm-raised". Never scored, only flagged. |
| allergens | 1 | flag | Flags the allergens you select in the panel. Does not change the score. |
| avoidList | 1 | flag | Flags any ingredient you have added to your own avoid list. Does not change the score. |

## Reviewed cross-cutting behavior

- Duplicate ingredient hits are charged once per rule; group collapse and saturation bound stacking.
- A sub-ingredient shares its parent position. Strains, qualifier claims and repeated allergen brackets do not shift ingredient ordering.
- Denials, advisories, function-word disclosures and named E-numbers are distinguished from ingredient presence.
- Whole-grain flour uses the separate optional gluten preference; whole-food mixture length is not itself a defect.
- Added/total sugar quantity replaces sugar-presence deductions when usable data exists; active quantity dials do not count the same grams twice.
- Invalid nutrition cannot generate bonuses or exaggerated penalties. Mass and volume stay distinct; missing data stays unknown.
- Source applicability, weaker-certification supersession and claim strength prevent duplicate sourcing credit.
- Allergens, diets, avoid-list matches and marketing advisories flag facts without altering a score.
- Rewards cannot breach ingredient ceilings. Floors, saturation, rounding and ceiling adjustments remain visible in balanced score rows.
- Duplicate/inherited goal IDs cannot add votes; importance and signed weights are bounded.
- Explicit custom weights remain saved. Revised defaults fill missing values; the rule revision retires cached scores.
- Every two-preset combination is checked across the calibration corpus and ceiling witnesses.
