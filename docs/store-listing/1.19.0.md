# Submission copy for 1.19.0

Understand grocery ingredient labels while shopping. Ingredient Check scores readable labels on
your computer and explains the ingredients and preferences that contributed to each score.

Choose goals and separate ingredient/allergen warnings, compare available labels and unit prices,
check pasted text or a local label photo, and save products into private local shopping lists.
Missing label data stays unavailable. A numerical score does not establish allergen absence.

Amazon.com is the primary validated shopping integration. Other retailers remain previews with
varying live verification. Amazon purchase-history saving and optional account sync require
separate choices; showing an item score does not enable either.

## Release artifacts and publisher steps

- Build with `npm run pack`; both Chrome and Firefox ZIPs carry version 1.19.0.
- Use the current icon and actual captured UI screenshots; do not invent product evidence.
- Link the updated public privacy policy, including standalone local photos, saved products and
  Orders score display independent of optional purchase-record saving.
- Submit through the publisher's Chrome Web Store account and Mozilla developer account.
  The generated Firefox ZIP is unsigned until Mozilla signs it. Keep the existing browser IDs.
- Validate sign-in redirects and upgrade preservation on the submitted builds before rollout.

This file prepares a reviewable submission; it does not claim a store listing was published.
