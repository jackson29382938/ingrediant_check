# Ingredient Check website

Static site for the Ingredient Check extension, deployed on Vercel. No build step.

- `index.html` landing page and install steps
- `privacy.html` privacy summary (full policy: `docs/PRIVACY.md`)
- `vercel.json` clean URLs and security headers

Preview locally: `npx serve website`, or open `index.html` in a browser.
Deploy: import this repository in Vercel with **Root Directory** set to `website`.
